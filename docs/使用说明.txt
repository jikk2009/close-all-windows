关窗 —— 一键关闭所有窗口
====================================================================

【它是什么】
一个很小的 Windows 小工具。装好以后，桌面上会多一个叫「关窗」的图标，
双击它（或者点任务栏上的图标），电脑上所有打开的窗口就会像你一个个
点了右上角的“×”那样关掉，全程不弹任何提示，一两秒就关完。


【装之前要知道】
  · 只支持 Windows 10 / Windows 11。
  · 安装需要管理员权限，会弹一次系统的"用户账户控制"窗口，点【是】即可。
  · 这是免费的绿色小工具，不联网、不收集任何东西；关的就是你屏幕上的窗口。


【怎么装（3 步）】
  1. 把压缩包解压到任意位置（桌面就行）。
  2. 右键「安装.cmd」→ 选【以管理员身份运行】。
     如果没有这个选项，先双击「安装.cmd」，弹出的提示里点【是】。
  3. 看到"安装完成"就装好了。桌面和开始菜单里会出现「关窗」。

  如果双击时 Windows 提示"已保护你的电脑"：
    点【更多信息】→【仍要运行】。


【怎么用】
  · 双击桌面「关窗」图标 → 所有窗口关闭。
  · 或者按快捷键 Ctrl + Alt + Shift + Q → 效果一样。

  想真正做到"点一下就关"：
    打开「开始」菜单 → 搜索「关窗」→ 右键 →【固定到任务栏】。
    之后点任务栏那个图标就行，永远不用找桌面。


【它不会关什么】
  · 不会关任务栏、桌面、开始菜单、输入法这些系统东西。
  · 不会强行结束程序（相当于替你点 ×），所以有没保存的文件，
    程序会自己弹"是否保存"让你选，不会悄悄丢东西。
  · 个别程序（比如微信、Clash）关掉窗口后会缩到右下角任务栏里继续运行，
    这是程序自己的行为，不是没关掉。


【怎么卸载】
  右键「卸载.cmd」→【以管理员身份运行】，会删掉程序、快捷方式和后台任务。
  任务栏上的图标如果还在，右键它 →「从任务栏取消固定」。


【常见问题】
  · 点了图标没反应？
    可能在后台任务被删了。重新运行「安装.cmd」即可修复。
  · 某个程序没关掉？
    多半是它正在问你"要不要保存"，或者它卡死了。
  · 想额外保留某些程序不关？
    需要懂一点点：用记事本打开
      %LOCALAPPDATA%\OneClickCloseAll\CloseAllWindows.ps1
    找到 $UserExclude 那一行，按里面的注释加程序名即可。
